# 1. 데이터 입출력의 개요
> 키보드로부터 데이터를 입력받아 화면이나 파일로 출력하는 것을 의미한다.
- 헝가리안 표기법
- 자료형
- 언어별 표현법
  - C언어
    - scanf
    - printf
    - puts, gets, putc, getc
  - Java
    - Scanner, nextInt, print, printf, println
  - python
    - input
    - print
``` C
// 키보드로 두 수를 입력받아 덧셈 출력
#include <stdio.h>
int main(void) {
    int i, j, k;
    scnaf("%d %d", &i, &j);
    k = i + j;
    printf("%d\n", k);
}
```
``` Java
import java.util.Scanner;
public class Test {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);
        int a = scan.nextInt();
        System.out.printf("a * 3 = %d\n", a * 3);
        System.out.println("a / 2 = " + (a/2));
        System.out.print("a - 1 = " + (a-1));
    }
}
```
