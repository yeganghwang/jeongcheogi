> 변수의 주소를 포인터라고 하고, 포인터를 저장할 수 있는 변수를 포인터 변수라고 한다.

``` C
#include <stdio.h>
int main(void) {
    int a=50;
    int *b = &a;
    *b = *b + 20;
    printf("%d, %d\n", a, *b);
    char *s;
    s = "google";
    for (int i=0; i<6; i+=2) {
        printf("%c, ", s[i]);
        printf("%c, ", *(s+i));
        printf("%s\n", s+i);
    }
}
```
