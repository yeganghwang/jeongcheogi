```python
a = [1, 2, 3, 4, 5]
x = 100
if x == 10:
    a = list(map(lamda num : num + 10, a))
elif x == 50:
    a = list(map(lamda num : num + 50, a))
else:
    a = list(map(lamda num : num + 100, a))
print(a)
```
- `lamda num : num + 100, a`: 인수로 입력된 값에 100을 더하는 람다 식
-  `map(..., a)`: 리스트 a의 각 요소를 ...에 적용한다.

결과:
```
[101, 102, 103, 104, 105]
```


``` python
Class Cls:
    x, y = 10, 20
    def chg(self):
        temp = self.x
        self.x = self.y
        self.y = temp
a = Cls()
print(a.x, a.y) #10 20
a.chg()
print(a.x, a.y) #20 10
```
