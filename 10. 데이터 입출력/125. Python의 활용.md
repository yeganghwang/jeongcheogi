# 1. 개요
- 자료형:
  - `리스트`
    - `pop(위치)`: 리스트의 '위치'에 있는 값을 출력하고 해당 요소를 삭제한다.
    - `index(값)`: 리스트에서 '값'이 저장된 요소의 위치를 반환한다
    - `count(값)`: 리스트에서 '값'이 저장되어 있는 요소들의 '개수'를 반환한다.
    - `extend(리스트)`: 리스트의 끝에 새로운 리스트를 추가하여 확장한다.
    - `reverse()`: 리스트의 순서를 역순으로 뒤집는다.
    - `sort()`: 리스트를 정렬하며 기본값은 오름차순이다. reverse True 하여 정렬 방식을 바꿀 수 있다. [2,1,3].sort(reverse=True) -> [3,2,1]
    - `copy()`: 리스트를 복사한다.
  - `세트`
    - `pop()`: 세트의 값을 출력하고 요소를 삭제한다.
    - `add(값)`: 세트에 값을 추가한다.
    - `update(세트)`: 세트에 새로운 '세트'를 추가하여 확장한다.
    - `remove(값)`: 세트에서 '값'을 찾아 해당 요소를 삭제한다.

``` python
x, y = input('입력: ').split('-') # xyz321-opq654
a = ['abc123', 'def456', 'ghi789']
a.append(x) #['abc123', 'def456', 'ghi789', 'xyz321']
a.append(y) #['abc123', 'def456', 'ghi789', 'xyz321', 'opq654']
a.remove('def456') #['abc123', 'ghi789', 'xyz321', 'opq654']
print(a[1][-3:], a[2][:-3], sep=',') # 789,xyz
for i in range(3, 6): # 3 4 5
    print(i, end = ' ')
```
결과:
```
789,xyz
3 4 5
```

```python
a = {'apple', 'lemon', 'banana'}
```
