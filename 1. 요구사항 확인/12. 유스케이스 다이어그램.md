# 1. 기능 모델링
- 개발될 시스템이 갖춰야 할 기능을 정리한 후 그림으로 표현한 것
- 전반적인 형태를 기능에 초점을 맞춰 표현
- 유스케이스 다이어그램, 액티비티 다이어그램
# 2. 유스케이스 다이어그램
- 개발될 시스템을 이용해 수행할 수 있는 기능을 사용자 관점에서 표현한 것
- 외부 요소와 시스템 간의 상호 작용 확인
- 사용자의 요구사항 분석 위한 도구
- 시스템의 범위 파악 가능
# 3. 유스케이스 다이어그램의 구성 요소
- 시스템
- 액터
  - 시스템과 상호작용을 하는 모든 외부 요소
  - 주로 사람이나 외부 시스템
  - 주액터: 사람, 부액터: 외부 시스템
- 유스케이스
  - 사용자 관점에서 시스템이 액터에게 제공하는 서비스나 기능
- 관계
  - 포함 <\<include>>
  - 확장 <\<extends>>
  - 일반화
