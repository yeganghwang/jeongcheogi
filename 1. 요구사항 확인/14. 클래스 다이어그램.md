# 1. 정적 모델링
> 사용자가 요구한 기능을 구현하는데 필요한 자료들의 논리적인 구조를 표현한 것
- 시스템에 의해 처리되거나 생성될 객체들 사이에 어떤 관련이 있는지를 구조적인 관점에서 표현
- 객체들을 클래스로 추상화하여 표현
- UML을 이용한 정적 모델링 -> 클래스 다이어그램

# 2. 클래스 다이어그램
- 클래스, 클래스의 속성, 클래스의 관계를 표현
- 구성 요소
  - 클래스
    - 각각의 객체들이 갖는 속성과 동작을 표현한 것
    - 3개의 구획으로 나눠 이름, 속성, 동작 표기
    - 속성: 클래스의 상태나 정보를 표현함
    - 오퍼레이션: 클래스가 수행할 수 있는 동작으로, 함수라고 함.
  - 제약 조건
    - 속성에 입력될 값에 대한 제약조건이나 오퍼레이션 수행 전후에 지정해야 할 조건이 있다면 적음.
    - 클래스 안에 제약조건을 기술할 때는 중괄호 { }를 사용
  - 관계
    - 클래스와 클래스 사이의 연관성을 표현
    - 연관관계, 집합관계, 포함관계, 일반화관계, 의존관계

# 3. 연관 클래스
> 연관 관계에 있는 두 클래스에 추가적으로 표현해야 할 속성이나 오퍼레이션이 있는 경우 생성하는 클래스
- 두 클래스의 연관 관계를 나타내는 선이 가운데 점선으로부터 점선을 연관 클래스로 이어 표현함
- 연관 클래스의 이름은 연관 관계의 이름을 통해 지정함
