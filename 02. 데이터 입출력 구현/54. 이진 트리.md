# 1. 이진 트리
> 차수가 2 이하인 노드들로 구성된 트리. 즉 자식이 둘 이하의 노드들로만 구성된 트리
- 이진 트리의 레벨 i에서 최대 노드의 수는 2^i-1 이다.
- 이진 트리에서 단말 노드의 수가 n0, 차수가 2인 노드 수가 n2라고 할 때, n0 = n2+1이 된다.

# 2. 트리의 운행법
> 트리를 구성하는 각 노드들을 찾아가는 방법을 운행법이라고 한다.
- 이진 트리를 운행하는 방법은 산술식의 표기법과 연관성을 갖는다.
- `Preorder`: Root -> Left -> Right
- `Inorder`: Left -> Root -> Right
- `Postorder`: Left -> Right -> Root

# 2. 수식의 표기법
> 이진 트리롤 만들어진 수식을 인오더, 프리오더, 포스트오더로 운행하면 각각 중위, 전위, 후위 표기법이 된다.
- `전위 표기법(Prefix)`: 연산자 -> Left -> Right. `+AB`
- `중위 표기법(Infix)`: Left -> 연산자 -> Right. `A+B` 
- `후위 표기법(Postfix)`: Left -> Right -> 연산자. `AB+`

## Infix 표기 변환
```
X = A/B*(C+D)+E
```
  ### Prefix로 변환하기
  1. 연산 우선순위에 따라 괄호로 묶는다.
    - (X = (((A/B)*(C+D))+E))
  1. 연산자를 해당 괄호의 앞으로 옮긴다
    - (X+(*(/(AB)+(CD))E))
  1. 필요없는 괄호를 제거한다.
    - (X+\*AB\*CDE)
  ### Postfix로 변환하기
  1. 연산 우선순위에 따라 괄호로 묶는다.
      - (X = (((A/B)*(C+D))+E))
  1. 연산자를 해당 괄호의 뒤로 옮긴다
      - (X (((AB)/(CD)+)*E)+)=
  1. 필요없는 괄호를 제거한다.
      - XAB/CD+*E+=
## Postfix나 Prefix를 Infix로 바꾸기
```
A B C - / D E F + * +
```
1. 인접한 피연산자 두 개와 오른쪽의 연산자를 괄호로 묶는다.
    - (A(B C -)/) (D(E F +) *) +
1. 연산자를 해당 피연산자의 가운데로 이동시킨다.
    - (A/(B-C))+(D*(E+F))
1. 필요 없는 괄호를 제거한다.
    - A/(B-C) + D*(E+F)
