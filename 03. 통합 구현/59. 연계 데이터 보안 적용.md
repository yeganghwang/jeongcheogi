# 1. 연계 데이터 보안
> 송신 시스템에서 수신 시스템으로 전송되는 연계 데이터는 보안에 취약할 수 있으므로 데이터의 중요성을 고려하여 보안을 적용해야 한다.
- 일반적인 연계 데이터의 보안 방식
  - 전송 구간 보안
  - 데이터 보안

# 2. 전송 구간 보안
> 전송되는 데이터나 패킷을 쉽게 가로챌 수 없도록 암호화 기능이 포함된 프로토콜을 사용한다.
- 데이터나 패킷을 가로채더라도 내용을 확인할 수 없게 데이터나 패킷을 암호화한다.

# 3. 데이터 보안
> 송신 시스템에서 연계 데이터를 추출할 때와 수신 시스템에서 데이터를 운영 DB에 반영할 때 데이터를 암, 복호화 하는 것이다.
- 데이터의 암 복호화 처리 절차
  - 송신 시스템
    1. DB에서 연계 데이터 추출
    1. 보안 적용 대상 컬럼을 암호화
    1. 연계 데이터를 인터페이스 테이블 또는 파일에 등록 및 송신
  - 수신 시스템
    1. 수신된 데이터 중 암호화한 컬럼을 복호화
    1. 운영 DB에 반영

# 4. 암복호화 적용 절차
1. 암호화 적용 대상, 암호화 알고리즘, 암호화 키 선정
1. 암호화 적용 대상 컬럼의 데이터 길이 변경
1. 암호화 알고리즘 라이브러리 확보 및 설치
1. 연계 응용 프로그램에서 암복호화 처리 수행
