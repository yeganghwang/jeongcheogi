# 1. 환경 변수
> 시스템 소프트웨어의 동작에 영향을 미치는 동적인 값들의 집합
- 변수명과 값으로 구성
- 시스템의 기본 정보를 저장
- 자식 프로세스에게 상속됨
- 시스템 전반에 걸쳐 적용되는 시스템 환경 변수와 사용자 계정 내에서만 적용되는 사용자 환경 변수로 구분

# 2. Windows의 주요 환경 변수
- `%OS%`
  운영체제의 종류를 나타냄
- `%PATH%`
  실행 파일의 경로를 지정함
- `%HOMEPATH%`
  사용자 홈 디렉터리 경로를 나타냄
- `%TEMP%`
  임시 파일이 저장되는 경로를 나타냄
- `%COMSPEC%`
  명령 해석기인 `cmd.exe`의 경로를 나타냄
- `%APPDATA%`
  응용 프로그램 데이터가 저장되는 경로를 나타냄

# 3. UNIX/LINUX의 주요 환경 변수
- `$HOME`
  사용자의 홈 디렉터리 경로를 나타냄
- `$PATH`
  실행 파일을 찾을 디렉터리 경로를 지정함
- `$PWD`
  현재 작업 중인 디렉터리 경로를 나타냄
- `$SHELL`
  사용 중인 셸의 경로를 나타냄
- `$USER`
  현재 로그인한 사용자 이름을 나타냄
- `$LANG`
  언어 및 로케일 정보를 지정함
